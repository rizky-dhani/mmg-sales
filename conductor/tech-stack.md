# Technology Stack: MMG Healthcare CRM

## Core Backend
- **Language:** PHP 8.2+
- **Framework:** Laravel 12
- **Admin Panel:** Filament 4
- **Security:** Spatie Laravel-Permission (RBAC)
- **Execution Environment:** Sail/Docker (development)

## Frontend & UI
- **Build Tool:** Vite 7
- **CSS Framework:** Tailwind CSS 4
- **Icons:** Heroicons
- **Components:** Filament UI Components

## Data & Storage
- **Database:** MariaDB (per README)
- **API Clients:** Guzzle (GuzzleHTTP)
- **CRM Logic:** Modular Schemas/Tables architecture in Filament

## Development & Quality
- **Testing:** Pest 4
- **Linting/Formatting:** Laravel Pint
- **Monitoring:** Laravel Pail
- **Debugging:** Laravel Tinker, Laravel Boost
